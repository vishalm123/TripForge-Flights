# tripforge-flights — rules for Claude

Part of TripForge (4 independent repos). The workspace plan is in `../TRIPFORGE_PLAN.md`.

## Ownership of work
- **The developer writes the application code** in `api/` and `web/` (Fastify, React, TypeScript). Claude teaches, gives focused exercises, and reviews strictly (Critical / Recommended / Optional). Claude does not write these files unless explicitly asked.
- **Claude may generate:** migrations, seed generator, validation SQL, `.env.example`, docs.
- **Docker, Compose, Kubernetes and CI files are learning work:** Claude teaches and reviews; the developer writes them. (`docker-compose.dev.yml` was generated by Claude before this rule existed and has been walked through.)

## Contracts
- `docs/openapi.yaml` is the source of truth. Change it *before* changing API behaviour.
- Error shape: `{ "error": { "code", "message", "details?" } }`. Codes: VALIDATION_ERROR 400, NOT_FOUND 404, SOLD_OUT 409, UNAVAILABLE 503, INTERNAL 500.
- Money is `NUMERIC(10,2)` in the DB. Never use floats for money arithmetic in SQL.
- Shared world: airports JFK/LAX/SFO/MIA/ORD; city codes NYC/LAX/SFO/MIA/CHI; data window 2027-03-01..2027-05-31.

## Database
- Only this service touches `tripforge_flights`.
- Schema changes go in a new dbmate migration; never edit an applied migration.
- Overbooking is prevented with a conditional atomic `UPDATE ... WHERE available_seats >= n` in the same transaction as the booking insert.
- After any change touching bookings, run `db/seed/validate.sql`.

## Verification language
Report status as Implemented / Compiled / Tested / Integrated / Verified. Never claim something works without running it.

## Commands (PowerShell, repo root)
- DB up: `docker compose -f docker-compose.dev.yml up -d postgres`
- Migrate: `docker compose -f docker-compose.dev.yml run --rm dbmate up`
- Seed: `python db/seed/generate.py` then `docker compose -f docker-compose.dev.yml exec -T postgres psql -q -U flights_svc -d tripforge_flights -f /db/seed/seed.sql`
- Validate: `docker compose -f docker-compose.dev.yml exec -T postgres psql -U flights_svc -d tripforge_flights -f /db/seed/validate.sql`
